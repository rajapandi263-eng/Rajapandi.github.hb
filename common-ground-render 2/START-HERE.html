Put Common Ground in Git, then connect Render

This package contains the shared server version with accounts, profiles, Power bumps and chat. It includes no existing user accounts, chat database or real environment secrets. Render receives a Git repository address after you upload these source files.

  1. Create a GitHub repository in your account. Suggested name: common-ground. Choose Private and initialize it with a README.
  2. In that repository, choose Add file → Upload files. Unzip the downloaded project, then upload the contents of the common-ground-render folder. Ensure package.json, server.mjs, render.yaml, public/ and test/ appear at the top level. Include .node-version and .gitignore. Commit the upload.
  3. Copy the repository address from your browser. Its format is https://github.com/YOUR-ACCOUNT/common-ground. That is an example format; use the actual address created in your account.
  4. In Render, choose Git Provider, connect that account and select the repository. A private repository uses this provider connection. The separate Public Git Repository field requires a public repository.
  5. For the included setup, choose New → Blueprint and select the repository. Review the paid service and 1 GB disk in render.yaml before confirming. If you are continuing New → Web Service, use the field values and environment variables in README.md.
  6. After deployment succeeds, give colleagues the app’s HTTPS onrender.com address and the pilot join code from Render’s Environment settings. Keep the join code out of your repository. Each person chooses Create account and uses their own email and password.

Accounts and chat require internet access. The join code controls pilot registration; employee identity verification, company SSO and email password reset are not included. The database remains on the attached Render disk. The source files have been tested locally; no Git repository or Render service has been created by this download.
