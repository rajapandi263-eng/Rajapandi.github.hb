Add Common Ground to your Home Screen, then sign in with the same account on your phone, tablet, or computer.

iPhone & iPad · Safari

Open this HTTPS site in Safari. Choose Share → Add to Home Screen (on iPad, choose View More if needed). Keep Open as Web App on if shown, then tap Add.

Android · Chrome

Choose More → Install and create shortcut → Install. Some Chrome versions show Install app or Add to Home screen.

One shared service

Accounts, profiles, Power bumps, and conversations are saved in this pilot’s shared service. Sign-in, profiles, and chat require internet access. The installed app can show a connection screen offline; changes are sent while you are online.

Use the same site address on every device.
